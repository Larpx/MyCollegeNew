# 项目概览

> 📖 本文档是 Wiki 的一部分 · [🏠 返回首页](./Home.md)

## 项目背景与目标

校园考勤管理系统基于 **.NET 10 + ASP.NET Core 10** 构建，面向高校考勤管理场景，提供管理员、教师（任课教师/辅导员）、学生三端功能。系统采用**垂直切片架构 (VSA) + CQRS + Minimal APIs**，覆盖考勤会话、二维码签到、请假审批、排课管理与统计报表全流程，并通过两轮安全审计形成完整的认证、授权、审计与配置安全体系。

---

## 核心功能模块

### 管理员

- 系统仪表盘：全局数据概览（学生数、教师数、课程数、出勤率）
- 组织架构管理：院系 → 专业 → 班级 → 学生四级组织树
- 教师管理：账号创建、角色分配（任课教师/辅导员）
- 学生管理：信息维护、班级分配、CSV 批量导入（自动生成 12 位随机密码并标记 `MustChangePassword`，首次登录强制改密）
- 课程管理：课程创建、学分设置、排课管理
- 统计报表：院系出勤率排名、趋势分析、Excel 导出

### 教师（任课教师 + 辅导员）

- 考勤会话：创建会话、查看进行中/历史会话
- 二维码签到：动态生成二维码（30 秒刷新），学生扫码签到
- 一键点名 / 随机点名：一键标记全班出勤、随机抽取学生
- 手动补签：为缺勤学生手动修改状态
- 请假审批（辅导员）：审批/驳回学生请假，通过后自动联动考勤记录
- 考勤统计：按课程/班级统计出勤率，Excel 导出

### 学生

- 扫码签到：扫描教师生成的二维码完成签到
- 请假申请：提交请假、查看审批状态
- 个人考勤：查看出勤记录与统计
- 课程表：查看已排课程与上课时间

## 技术栈

| 层次 | 技术 |
|------|------|
| 运行时 | .NET 10 |
| 架构 | 垂直切片架构 (VSA) + CQRS |
| API | Minimal APIs |
| 中介者 | MediatR |
| 校验 | FluentValidation |
| 映射 | Mapster |
| ORM | SqlSugar Core（SQLite / MySQL） |
| 前端 | Blazor Web App（SSR + InteractiveServer） |
| 认证 | JWT Bearer + HttpOnly Cookie (BFF) |
| 文档 | Scalar |
| 日志 | Serilog |
| 缓存 | IDistributedCache + Redis |
| 监控 | OpenTelemetry |
| 编排 | .NET Aspire |
| 测试 | xUnit |
| 部署 | Docker Compose（Linux） |

## 项目结构

```
src/
├── Campus.Attendance.Shared/          # 共享内核（实体、枚举、DTO、异常、常量、接口）
├── Campus.Attendance.Infrastructure/  # 基础设施（SqlSugar、Token、用户上下文）
├── Campus.Attendance.Api/            # API 入口（Minimal APIs + 垂直切片）
│   └── Features/                     #   按功能组织的切片（Auth/Users/Organization/...）
├── Campus.Attendance.Web/            # Blazor Web App
├── Campus.Attendance.Tests/          # xUnit 单元测试
├── Campus.Attendance.AppHost/        # .NET Aspire 编排器
└── Campus.Attendance.ServiceDefaults/ # Aspire 服务默认配置
```

| 项目 | 职责 |
|------|------|
| Shared | 实体、DTO、枚举、异常、常量、接口（被所有层引用） |
| Infrastructure | SqlSugar 集成、Token 生成、用户上下文、审计服务 |
| Api | Minimal APIs 入口，按 Feature 切片组织，CQRS + MediatR |
| Web | Blazor Web App，BFF 模式，三端页面 |
| Tests | xUnit 单元测试，内存 SQLite 隔离 |
| AppHost | .NET Aspire 本地编排 |
| ServiceDefaults | OpenTelemetry、健康检查、服务发现默认配置 |
