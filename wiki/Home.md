# 考勤管理系统 Wiki

基于 **.NET 10 + ASP.NET Core 10** 的校园考勤管理系统，采用**垂直切片架构 (VSA) + CQRS + Minimal APIs**，支持管理员、教师（任课教师/辅导员）、学生三端功能，覆盖考勤会话、二维码签到、请假审批、排课管理与统计报表全流程。

> 本 Wiki 是项目文档的导航入口，提炼要点并在 Gitee / GitHub 仓库浏览器中良好展示。详细内容请参阅 [`docs/`](../docs/) 目录下的完整文档。

---

## 核心特性

- **多角色三端**：管理员 / 任课教师 / 辅导员 / 学生，角色策略隔离，权限精确到端点
- **考勤全流程**：考勤会话创建、二维码动态签到（30 秒刷新）、一键点名、随机点名、手动补签
- **排课与组织**：院系 → 专业 → 班级 → 学生四级组织树，课程管理与排课
- **双因素认证 (2FA)**：TOTP 验证码 + 重放保护 + 速率限制 + 失败锁定
- **安全审计**：登录、改密、2FA、用户增删、批量导入等敏感操作全程审计留痕
- **跨平台部署**：Docker Compose（Linux）一键编排，SQLite/MySQL 可切换，Blazor Server 跨浏览器渲染

## 技术栈

| 层次 | 技术 |
|------|------|
| 运行时 | .NET 10 |
| 架构 | 垂直切片架构 (VSA) + CQRS |
| API | Minimal APIs + MediatR |
| 校验 / 映射 | FluentValidation + Mapster |
| ORM | SqlSugar Core（SQLite / MySQL） |
| 前端 | Blazor Web App（SSR + InteractiveServer） |
| 认证 | JWT Bearer + HttpOnly Cookie (BFF) |
| 缓存 | IDistributedCache + Redis |
| 编排 | .NET Aspire |
| 文档 / 日志 / 监控 | Scalar / Serilog / OpenTelemetry |
| 测试 | xUnit |
| 部署 | Docker Compose（Linux） |
