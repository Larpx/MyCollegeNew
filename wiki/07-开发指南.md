### user-secrets 配置

第二轮安全审计（L-5）后，`appsettings.Development.json` 中的 `Jwt:SecretKey` 已置空，`Campus.Attendance.Api.csproj` 添加了 `UserSecretsId`，DEBUG 模式下会自动生成随机密钥。建议使用 `dotnet user-secrets` 显式管理本地密钥：

```bash
cd src/Campus.Attendance.Api
dotnet user-secrets init
dotnet user-secrets set "Jwt:SecretKey" "你的开发环境密钥-至少32字符长度"
dotnet user-secrets set "Db:ConnectionString" "DataSource=attendance.db"
dotnet user-secrets set "Cors:AllowedOrigins:0" "https://localhost:7088"
dotnet user-secrets list
```

> **注意**：`appsettings.json` 中的 `Db:ConnectionString` 与 `appsettings.Development.json` 中的 `Jwt:SecretKey` 已置空，启动时强制校验，缺失则抛出异常阻止启动。

## 代码规范

### 命名约定

| 类型 | 规范 | 示例 |
|------|------|------|
| 类 / 方法 | PascalCase | `LoginHandler`、`GenerateToken` |
| 参数 / 变量 | camelCase | `userId`、`captchaToken` |
| 私有字段 | `_camelCase` | `_logger`、`_currentUser` |
| 接口 | I 前缀 | `IAuditService`、`ICurrentUser` |
| 异步方法 | Async 后缀 | `RevokeAsync`、`LogAsync` |

### 其他规范

- **块作用域命名空间**：使用 `namespace Foo;` 而非 `namespace Foo { ... }`
- **异步优先**：公共方法异步优先，Handler 和 Endpoint 接收 `CancellationToken`
- **依赖注入**：构造函数注入，配置使用 `IOptions<T>`
- **时间**：统一使用 `DateTime.UtcNow`
- **日志**：`ILogger<T>` 结构化日志，如 `_logger.LogInformation("用户 {UserId} 执行操作", userId)`
- **异常**：业务异常用 `BusinessException`，系统异常统一返回 `ProblemDetails`（RFC 7807）

## 安全开发规范

### 密码策略（L-1）

所有涉及密码设置的 Validator 必须调用 `ApplyPasswordPolicy()` 扩展方法：

- 位置：`Api/Validation/PasswordValidationExtensions.cs`
- 规则：至少 8 位、必须包含大写字母、小写字母和数字
- 用法：

```csharp
public class ChangePasswordValidator : AbstractValidator<ChangePasswordCommand>
{
    public ChangePasswordValidator()
    {
        RuleFor(x => x.NewPassword).ApplyPasswordPolicy();
        // 其他规则...
    }
}
```

> 禁止在 Validator 中手写密码正则，必须复用 `ApplyPasswordPolicy()` 保证策略一致。

### 审计日志（M-5）

敏感操作必须通过 `IAuditService` 记录审计日志，写入 `AuditLog` 实体：

```csharp
public class ChangePasswordHandler : IRequestHandler<ChangePasswordCommand, Result>
{
    private readonly IAuditService _auditService;

    public async Task<Result> Handle(ChangePasswordCommand cmd, CancellationToken ct)
    {
        // ... 业务逻辑 ...
        await _auditService.LogAsync("password.change", targetUserId, ct);
        return Result.Success();
    }
}
```

需记录的操作：登录成功/失败、密码修改/重置、2FA 绑定/验证、用户增删、CSV 批量导入。

> `IAuditService.LogAsync(action, target, ct)` 会自动记录当前 `ICurrentUser` 的 UserId、IP、UserAgent 等上下文信息。

### CSV 批量导入（L-2、M-6）

- **随机密码**：使用 `System.Security.Cryptography.RandomNumberGenerator` 生成 12 位随机密码，禁止使用学号或固定默认密码
- **强制改密标记**：导入时 `Student.MustChangePassword = true`，首次登录强制跳转 `/force-change-password`
- **异常脱敏（M-6）**：导入异常禁止将 `ex.Message` 原样返回客户端，应返回通用错误信息，详细信息仅写入日志
- **审计记录**：导入完成后通过 `IAuditService` 记录批量导入操作

### 安全编码规范

| 规范 | 要求 |
|------|------|
| 异常脱敏 | 面向客户端的响应禁止包含 `ex.Message`、堆栈、内部字段名（M-6） |
| 安全响应头 | `SecurityHeadersMiddleware`（L-4）已统一注入，禁止在控制器中重复设置或覆盖 |
| CORS | 跨域来源通过 `Cors:AllowedOrigins` 白名单配置（M-7），禁止 `AllowAnyOrigin` |
| 2FA 密钥传输 | TOTP 密钥与二维码必须通过 `IDistributedCache` 服务端会话存储（M-4），禁止非 HttpOnly Cookie |
| JWT 撤销 | 登出必须调用 `TokenRevocationService.RevokeAsync(jti, expiry)`（M-3），禁止仅清除客户端 Cookie |
| 配置校验 | 数据库连接字符串、JWT SecretKey 启动时强制校验非空（H-5、L-5），禁止硬编码或使用默认值 |

## 项目结构与 VSA 架构约定

```
src/
├── Campus.Attendance.Shared/         # 共享内核（实体、枚举、DTO、异常、常量、接口）
├── Campus.Attendance.Infrastructure/ # 基础设施（SqlSugar、Token、用户上下文）
├── Campus.Attendance.Api/           # API 入口（Minimal APIs + 垂直切片）
│   └── Features/                    #   按功能组织的切片
├── Campus.Attendance.Web/           # Blazor Web App
├── Campus.Attendance.Tests/         # xUnit 单元测试
├── Campus.Attendance.AppHost/       # .NET Aspire 编排器
└── Campus.Attendance.ServiceDefaults/# Aspire 服务默认配置
```

### 如何添加新功能（VSA 切片）

1. 在 `Api/Features/{Feature}/` 下创建子目录（如 `CreateXxx/`）
2. 创建文件：
   - `CreateXxxEndpoint.cs` — Minimal API 路由注册
   - `CreateXxxCommand.cs` — CQRS 请求（Command/Query）
   - `CreateXxxHandler.cs` — 业务逻辑
   - `CreateXxxValidator.cs` — FluentValidation 校验
3. 在 `Shared/Features/{Feature}/` 下创建 DTO
4. 在 `Features/Endpoints.cs` 中注册路由模块
5. 编写对应的单元测试

### 架构原则

- **垂直切片**：每个功能模块代码集中在同一目录
- **CQRS**：Command/Query 分离，通过 MediatR 解耦
- **防重复**：共享代码提取到 `Shared`，禁止跨切片复制
- **切片间通信**：通过 MediatR 发送请求，禁止直接引用 Handler

## 贡献流程

### 提交规范

```
feat: 新增功能
fix: 修复缺陷
refactor: 重构代码
docs: 文档更新
test: 测试相关
chore: 构建/工具变更
```

### 测试规范

- **框架**：xUnit
- **模式**：AAA（Arrange-Act-Assert）
- **命名**：`Method_Scenario_ExpectedResult`
- **运行**：`dotnet test src/Campus.Attendance.Tests`

### 构建验证要求

- 0 错误，0 警告
- 全部单元测试通过
