# 校园考勤管理系统 · 用户使用说明

本说明面向最终使用者（管理员、教师、学生），介绍系统是什么、需要什么环境、如何启动以及各角色的常用操作。不涉及任何技术实现细节。

---

## 一、这是什么

校园考勤管理系统是一套面向学校的考勤与课程管理平台，支持三类角色：

- **管理员**：维护组织架构、师生账号、课程，查看全校考勤统计。
- **教师**（任课教师 / 辅导员）：发起考勤、点名、审批请假、查看所辖班级考勤。
- **学生**：扫码签到、提交请假、查看个人考勤与课表。

系统提供 Web 界面，浏览器访问即可使用，无需安装客户端。

---

## 二、运行前需要准备什么

| 项目 | 要求 |
|------|------|
| 浏览器 | 现代浏览器（Chrome / Edge / Firefox 最新版） |
| 网络 | 能访问系统部署地址（本地或公网域名） |
| 账号 | 由管理员分配，首次登录可能需要修改密码 |

> 如果你是要自己部署系统，请参阅 [开发说明](开发说明.md) 中的部署章节。

---

## 三、程序大致怎么跑

1. **管理员** 登录后台，先建好「院系 → 专业 → 班级」组织架构，再录入教师与学生账号、开设课程并排课。
2. **教师** 上课时登录，创建一次考勤会话，系统生成一个动态二维码；学生在规定时间内扫码完成签到，教师也可一键点名或手动补签。
3. **学生** 用手机扫描教师展示的二维码签到，或提交请假申请交由辅导员审批；课后可在个人中心查看自己的出勤记录与课表。

## 四、各角色常用功能

### 管理员

- **仪表盘**：查看全校学生数、教师数、课程数、整体出勤率。
- **组织架构**：维护院系、专业、班级三级树形结构。
- **教师管理**：新增教师账号、分配角色（任课教师 / 辅导员）。
- **学生管理**：单个新增或通过 Excel 表格批量导入学生（导入后系统为每人生成随机密码，学生首次登录需强制修改）。
- **课程管理**：创建课程、设置学分、安排上课时间。
- **统计报表**：按院系查看出勤率排名与趋势，可导出 Excel。

### 教师

- **考勤会话**：创建一次点名，查看进行中与历史会话。
- **二维码签到**：系统每 30 秒刷新一次二维码，学生扫码签到。
- **一键点名**：快速将全班标记为出勤。
- **随机点名**：随机抽取学生提问，避免连续重复。
- **手动补签**：为缺勤学生手动修改考勤状态。
- **请假审批**（辅导员）：审批或驳回学生请假，通过后自动联动考勤记录。
- **考勤统计**：按课程 / 班级统计出勤率并导出。

### 学生

- **扫码签到**：扫描教师生成的二维码完成签到。
- **请假申请**：提交请假并查看审批进度。
- **个人考勤**：查看自己的出勤记录与统计。
- **课程表**：查看已排课程与上课时间。

## 五、常见问题

| 现象 | 解决动作 |
|------|----------|
| 首次登录被要求改密码 | 这是批量导入账号的安全策略，按页面提示设置新密码（至少 8 位，需含大小写字母和数字）后重新登录 |
| 扫码后提示二维码已过期 | 二维码每 30 秒刷新，请扫描教师屏幕上最新的二维码 |
| 登录提示「用户名或密码错误」 | 检查用户名密码是否正确；若忘记密码，请联系管理员重置 |
| 教师看不到自己带的班级 | 联系管理员确认你的账号已正确分配角色与班级 |
| 页面打不开 | 确认访问地址正确、网络通畅；若自行部署，参考 [开发说明](开发说明.md) 排查 |
| 提交请假后一直未审批 | 请联系你的辅导员；辅导员在「请假审批」中处理 |
