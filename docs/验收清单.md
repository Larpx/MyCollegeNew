# 验收清单

## 项目结构

- [x] 所有项目目标框架 `net10.0`

## 技术栈合规
- [x] Minimal APIs 路由注册

- [x] FluentValidation 管道自动校验
- [x] Mapster 对象映射

## 数据库
- [x] 开发环境使用 SQLite，零配置启动
- [x] 生产环境使用 MySQL，连接字符串通过环境变量注入
- [x] 启动时 CodeFirst 自动建表 + 种子数据播种
- [x] 连接字符串无硬编码，通过 `IOptions<DbConfig>` 注入

## 认证与安全
- [x] JWT Bearer Token 认证，BCrypt 密码哈希
- [x] BFF 模式：JWT 存储在 HttpOnly Cookie，禁止 localStorage
- [x] 角色路由守卫生效：学生/教师/管理员端互斥
- [x] 安全响应头：X-Content-Type-Options、X-Frame-Options、X-XSS-Protection
- [x] 系统异常返回 ProblemDetails，不暴露内部细节
- [x] Blazor 防伪令牌
- [x] 请求限流 + 响应压缩（Brotli + Gzip）

## 考勤核心功能
- [x] 教师可创建考勤会话并生成动态二维码（30 秒刷新）
- [x] 学生扫码签到，状态判定正确（正常/迟到/缺勤）
- [x] 二维码 Token 过期后签到被拒绝
- [x] 一键点名可批量标记全班出勤
- [x] 随机点名避免连续重复
- [x] 手动补签功能
- [x] 请假审批流闭环：申请 → 审批 → 考勤自动联动
